# CloudReady Africa

CloudReady Africa is an unofficial, beginner-friendly AZ-900 exam preparation tool designed to help learners practise Azure Fundamentals concepts.

## Features

- **Smart Quiz:** Practise original questions aligned with Azure Fundamentals learning topics, with feedback and explanations.
- **Flashcards:** Review important Azure concepts.
- **Study Planner:** Organise your preparation.
- **Study Buddy:** Explore guided explanations of key concepts.
- **Readiness Tracker:** Track your study progress and readiness.

## How to Run

1. Download or clone this repository.
2. Open the project folder in Visual Studio Code.
3. Open `index.html` in your browser, or use the Live Server extension in VS Code.
4. Explore the five learning features.

## Technologies

- HTML
- CSS
- JavaScript
- Browser local storage for saving progress
